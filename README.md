# Моя музыка

Личный плеер для музыки и фильмов. Работает как приложение на телефоне (PWA), всё хранится на устройстве владельца.

- `public/` — готовое приложение, его публикует Netlify
- `src/player.html` — исходник плеера, `src/build.py` собирает из него `public/`
- `src/dj.html`, `src/dj.css`, `src/dj.js` — DJ-пульт (две деки, EQ, фильтр, кроссфейдер, BPM, SYNC, петли); `build.py` вставляет их в `public/index.html`

Сборка: `cd src && python3 build.py <номер версии>`
- DJ-пульт умеет записывать микс (кнопка REC → WAV → «Сохранить в библиотеку» или «Скачать»)
- `src/ed.*` — «Монтаж»: клипы и фото, обрезка, разрез, музыка из библиотеки, титры, подгонка под бит (через `DJ.analyzeTrack`), запись в mp4 через canvas + MediaRecorder
- Монтаж: вкладка «Эффекты» (переходы между фото: плавный и сдвиг, наезд на фото), настройки сохраняются вместе с проектом

## Герои из рисунка (src/scan.js + вкладка «Герои» в Монтаже)
Фото рисунка → вырезка героев на телефоне (без интернета): поиск светлых листов, цвет бумаги с учётом света, разделение склеенных героев. Герои рисуются поверх клипов и пляшут в такт музыке (ритм из DJ.analyzeTrack), двигаются пальцем по кадру, сохраняются в проекте.
